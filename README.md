# Make the AI judge happy — entry

A tiny orange kitten laughing with its eyes squeezed shut, peeking out
from inside a giant sunflower, paws gripping the petals, bees and
butterflies around it under a bright blue sky.

Why this image: the laugh is unmistakable at first glance, the idea is a
small surprise of its own (a kitten living inside a sunflower, framed by
the bloom like a portrait), the warm yellow-gold palette pulls toward one
happy mood, and the giant flower fills the frame so the joke still lands
at 300 pixels across.

## Files

- `entry.png` — the image (JPEG bytes, 1024×1024, 215.364 bytes, under
  the 1 MiB cap; the name stays `entry.png`, the format is told apart by
  its first bytes).
- `main.py` — copies `entry.png` to `/output/entry.png`, deterministically
  (no network, no randomness, no clock), so both runs write identical bytes.
